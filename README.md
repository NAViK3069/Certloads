# Certloads

ชุดเครื่องมือช่วยงานเอกสาร ใช้งานผ่านเว็บ — ประมวลผลในเบราว์เซอร์ทั้งหมด ไม่อัปโหลดไฟล์ขึ้นเซิร์ฟเวอร์

## เครื่องมือ

### Certificate
อัปโหลด PDF ใบประกาศหลายหน้า (เช่นไฟล์ที่ export จาก Canva) แล้วเลือก:

- **แยกไฟล์** — 1 หน้า = 1 ไฟล์ ตั้งชื่อไฟล์จากชื่อผู้รับอัตโนมัติ (`{ชื่อ}`, `{ลำดับ}`, `{นามสกุล}` …) ดาวน์โหลดเป็น ZIP / ทีละไฟล์ / รวมหน้าที่เลือก
- **ดึงข้อมูลเป็นตาราง** — จับชื่อ-นามสกุล, คำนำหน้า, หลักสูตร, วันที่, หน่วยงาน แก้ไขในตารางได้ ลาก/กดลูกศรเพื่อสลับคอลัมน์ ส่งออก Excel / CSV / คัดลอกไปวางใน Sheets
- **แก้ไขโดยละเอียด** — แสดงรูปใบประกาศพร้อมกรอบทุกบรรทัด คลิกข้อความแล้วผูกกับ `{ชื่อ}`, `{นามสกุล}`, `{เลขที่}`, `{รหัส}`, `{หลักสูตร}` … หรือช่องที่สร้างเอง ตัดคำนำหน้า/ท้ายได้ (เช่น "วันที่") ระบบจับคู่บรรทัดในหน้าอื่นจาก**ตำแหน่งและขนาดตัวอักษร** ไม่ใช่จากคำ จึงใช้ได้กับใบที่ข้อความ/สไตล์ต่างกัน

หมายเหตุ: PDF ที่เป็นภาพสแกน (ไม่มีข้อความ) แยกไฟล์ได้ แต่ยังดึงข้อมูลเป็นตารางไม่ได้

## พัฒนา

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # ได้ไฟล์ static ใน dist/ เอาไป deploy ที่ไหนก็ได้ (Vercel, Netlify, GitHub Pages)
```

โครงสร้าง
- `src/lib/pdf.ts` — อ่าน PDF ด้วย pdf.js, รวมข้อความเป็นบรรทัด, กู้วรรณยุกต์ไทยที่ฟอนต์ไม่มี Unicode
- `src/lib/certificate.ts` — ตรวจหาช่องอัตโนมัติ (ชื่อ = ตัวใหญ่สุด, อื่น ๆ จากคำสำคัญ) → Mapping (บรรทัด↔ช่อง) → จับคู่ตำแหน่งในทุกหน้า → ตาราง
- `src/lib/files.ts` — แยก PDF (pdf-lib), ZIP (JSZip), Excel (SheetJS), CSV
- `src/tools/<tool>/` — หน้าจอของแต่ละเครื่องมือ
